# 1. THE RESEARCH QUESTION

**Title:** Information Diffusion in US Equity Markets: An Event Study of Earnings-Related SEC Filings, 2021–2025.

**Question:** Following earnings-related Form 8-K Item 2.02 filings, do unusually large initial abnormal stock returns exhibit continuation or reversal over the following five trading sessions, relative to comparable large price movements without such filings?

This is an empirical event study, NOT a general stock-price prediction or algorithmic trading project.

The goal is to measure and evaluate the temporal pattern of market-adjusted information responses.

Be extremely careful with attribution:

- The EDGAR acceptance timestamp is not necessarily the first public earnings-announcement timestamp.
- An earnings press release may precede the 8-K filing.
- Daily prices cannot identify intraday information-diffusion speed.
- A significant result does not establish a causal market inefficiency.
- The study must consistently describe results as filing-timed reactions unless release timing is independently verified.

Never call an 8-K a clean earnings-surprise event without evidence about the original release.

# 3. HYPOTHESES

Define for each valid event:

AR(0): day-zero abnormal return.

CAR(+1,+5): sum of abnormal returns for sessions +1 through +5.

signed_post_CAR = sign(AR(0)) × CAR(+1,+5).

A positive signed_post_CAR represents continuation in the direction of the initial response.

A negative signed_post_CAR represents reversal.

Construct matched non-event large-move controls using the same definitions.

**Primary null hypothesis H0:**

The average signed_post_CAR for qualifying filing events is no greater than that of comparable matched non-filing large-move observations.

**Primary alternative hypothesis H1:**

The average signed_post_CAR for qualifying filing events is greater than that of comparable matched non-filing large-move observations.

Primary estimand:

Mean(event signed_post_CAR minus matched-control signed_post_CAR), expressed in percentage points.

This is a one-sided continuation hypothesis.

Also report two-sided confidence intervals and the corresponding two-sided statistical results.

A statistically insignificant or negative difference is a valid finding.

Do not redefine the hypothesis after observing outcomes.

# 8. EXPECTED-RETURN MODEL

Compute daily simple adjusted returns:

R(i,t) = P(i,t) / P(i,t-1) - 1.

Estimate, for every event, the market model using only sessions [-120,-21]:

R(i,t) = alpha(i) + beta(i) × R(SPY,t) + epsilon(i,t).

Use OLS on paired valid company/SPY observations.

Require 100 complete paired observations for the primary clean sample. Otherwise exclude with an exact coverage reason. Report how much sample is lost because of this requirement.

Do not fit or refit the model using event-period or post-event returns.

Expected return:

E[R(i,t)] = alpha(i) + beta(i) × R(SPY,t).

Abnormal return:

AR(i,t) = R(i,t) - E[R(i,t)].

Cumulative abnormal return:

CAR(i,a,b) = sum of AR(i,t), for t from a through b.

These are additive CARs, not compounded buy-and-hold returns.

Calculate and store:

- alpha and beta
- Model R-squared
- Residual standard deviation
- AR for every event-window session
- CAR[-5,-1]
- AR[0]
- CAR[0,+1]
- CAR[-1,+1]
- CAR[+1,+5]
- CAR[+1,+10]
- signed_post_CAR[+1,+5]

Use decimal returns internally and label percentage versus percentage-point results clearly.

Do not confuse signed CAR with standardized CAR. Use unambiguous variable names.
